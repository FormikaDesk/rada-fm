# rada-tui

The terminal interface of [rada](https://github.com/formikadesk/rada-fm), a terminal file
manager, built on [ratatui](https://ratatui.rs) and crossterm: panels, tabs, menus, themes,
previews and the file chooser, on top of [`rada-core`](https://crates.io/crates/rada-core).

This crate is published so that `cargo install rada --locked` can build the program. It is
released together with `rada` and `rada-core`, and **has no stable API**: any release may
change it. If you want a file manager, install [`rada`](https://crates.io/crates/rada).
